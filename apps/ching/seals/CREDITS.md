# Seal image credits

The 64 hexagram seals in `svg/` are built from small seal script (小篆) character drawings on Wikimedia Commons, from the Ancient Chinese characters project (https://commons.wikimedia.org/wiki/Commons:Ancient_Chinese_characters_project). The Commons API reports each source file as public domain or CC0; the licence of each file is listed below. The glyph outlines were taken from the files, transformed (scaled, translated, and in one case rotated) and cut out of a red block. Fourteen characters with no seal file on Commons (坤 訟 噬 剝 遯 壯 晉 睽 損 益 姤 渙 既 濟) were composed from the component files listed for them in `manifest.json`; for 渙 the component 奐 was taken from 喚-seal.svg with its left-hand 口 removed. The colours, the frame, the layout and the composition of those characters are original to this project. The Commons file `乾-seal.svg` is a redirect to `ACC-s10941.svg`, which is the file used.
